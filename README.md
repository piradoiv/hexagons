# Hexagonal Grids for Xojo
This is a (🚧 work in progress ⚠️) Xojo Library implementing the [Hexagonal Grids](https://www.redblobgames.com/grids/hexagons/) by [Red Blob Games](https://www.redblobgames.com/). The code has been ported from the [generated TypeScript implementation](https://www.redblobgames.com/grids/hexagons/codegen/output/lib.ts).
